# Masquerade the Agent process

The Agent rewrites its process title, thread name and command line to a neutral daemon name so that an attacker who reaches a Trap host cannot recognize it in a process listing. The name defaults to `syslog-relay` and is configurable through `PROCESS_MASK_NAME`; `agent/install.sh` installs the same neutral name as the system user, install directory and systemd unit. This supersedes ADR-0007: the earlier decision treated the disguise as pointless, but the work plan makes host-level masking a Must requirement (MASK-4), and a recognizable Agent process would let an attacker burn an already-deployed Trap. The honest description of the disguise lives here and in `docs/deployment.md` so the risk of an administrator misreading the service name is bounded.

The container delivery uses the same neutral system identity and filesystem layout as native installation. Both levels run a `relay.pyz` bundle with neutral internal module paths; the source repository's package layout is retained only for development. Runtime image, container, network and volume names are neutral. This is consistent naming for the deployed service, not a promise that source inspection cannot reveal its purpose.
