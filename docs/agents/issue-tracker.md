# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues at `ArtiKn/HoneyForge`. Use the `gh` CLI for tracker operations and infer the repository from the configured Git remote.

## Conventions

- Create issues with `gh issue create`.
- Read issues with `gh issue view`.
- Apply and remove labels with `gh issue edit`.
- Comment with `gh issue comment` and close with `gh issue close`.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read it from GitHub Issues.

## Pull requests as a triage surface

**PRs as a request surface: no.**

Pull requests are not included in the request-triage queue unless this setting is deliberately changed later.
